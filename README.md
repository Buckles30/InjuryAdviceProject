This Streamlit website serves as a GAA injury tracker that logs new cases automatically categorises them into standardised areas
and analyses historical data to predict estimated return-to-play timelines and positional trends. To run it you'll need
Python installed along with the streamlit and pandas libraries (pip install streamlit pandas)
aswell as the accompanying Kaggle dataset (Injuries.csv) saved in the same folder as your script.
https://www.kaggle.com/datasets/sananmuzaffarov/european-football-injuries-2020-2025
